# Sistema de Cálculo de Lucro MEI - ContTech

**🔗 Site ao vivo:** https://dossantosangela22k-arch.github.io/Sistema-lucro-mei/

### 🎯 Objetivo
Ajudar Microempreendedores Individuais (MEI) a calcular lucro mensal real de forma simples e rápida. Projeto ContTech que une minha formação em Ciências Contábeis + Análise e Desenvolvimento de Sistemas.

### ✨ Funcionalidades Premium
- ✅ Cálculo de lucro com separação de despesas fixas e variáveis
- ✅ Margem de lucro automática em %
- ✅ Alerta visual: verde para lucro (#22c55e), vermelho para prejuízo
- ✅ Simulador de meta: "Quanto preciso faturar para lucrar R$ X?"
- ✅ Histórico dos últimos 5 cálculos com LocalStorage
- ✅ Exportar relatório em PDF (jsPDF)
- ✅ Design responsivo ContTech - Paleta #0f172a + #22c55e
- ✅ Dica de isenção de IR para MEI até R$ 81.000

### 💻 Tecnologias
- HTML5, CSS3, JavaScript puro
- LocalStorage API
- jsPDF para exportação de relatório
- GitHub Pages
- Paleta ContTech Premium: Navy #0f172a + Green #22c55e

### 🧠 O que aprendi
- Criar repositórios, usar branches, fazer commits
- Organizar código com separação HTML/CSS/JS
- Lógica de cálculo financeiro e margem de lucro
- UX para MEI - campos com R$, placeholders, feedback visual
- Integração de biblioteca externa (jsPDF)
- Deploy com GitHub Pages

### 📊 Diferencial ContTech
Como Bacharela em Ciências Contábeis, separei despesas fixas (aluguel, DAS) de variáveis (material, frete) e mostro % de cada uma - visão que MEI não tem em calculadora simples.
