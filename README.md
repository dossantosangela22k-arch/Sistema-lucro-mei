# Sistema de Cálculo de Lucro para MEI - ContTech

### 🎯 Objetivo do Projeto
Resolver a falta de controle financeiro de MEIs que misturam contas pessoais e da empresa. Criar uma ferramenta web simples para calcular lucro líquido e margem mensal.

### 💻 Tecnologias Utilizadas
- HTML5, CSS3, JavaScript
- Git e GitHub para versionamento
- GitHub Pages para hospedagem

### 📚 O que foi aprendido
- Transformar regra contábil (Lucro = Receita - Despesa) em código
- Criar UX simples para público não técnico
- Organizar projeto em diretórios (src, assets, docs) e documentar com README cristalino
- Usar background em Contábeis como diferencial em ContTech
